Contextual literal classification and widening

src/contextual_literals.rs contains code adapted from pingdotgg/ts-rust,
commit 22ae6fa87aed1d4bde7272ab68452fae1f928e4a (checker_p28.rs and checker_p30.rs).
https://github.com/pingdotgg/ts-rust

That code is a Rust port of the native TypeScript compiler,
Microsoft TypeScript commit 673a5f17d713bdc8c7185f18a9c11e3c4ac5d781:
checker.go isLiteralOfContextualType, maybeTypeOfKind,
getWidenedLiteralType, getWidenedUniqueESSymbolType and
getWidenedLiteralLikeTypeForContextualType.
https://github.com/microsoft/TypeScript
Copyright (c) Microsoft Corporation. Licensed under the Apache License, Version 2.0.

Changes made here: native Type variants replace flags and arena IDs;
aliases, enum members, boolean/optional wrappers and lexical constraints
are resolved through adapters to the existing checker. Constraint cycles
are detected and acyclic chains are preserved.
Literal freshness comes from the native expression and binding metadata.
Array initialization preserves the resulting regular element types;
generic element diagnostics and unique-symbol array display are integrated
with the native checker. The generic element guard follows
relater_p1.rs elaborateArrayLiteral / elaborateElement.

The license texts are retained in licenses/ts-rust-MIT.txt and
licenses/TypeScript-Apache-2.0.txt. Other original code in this crate
remains under the repository's MIT license.

Source-aware signature type-node serialization

src/type_nodes.rs adapts parameterToParameterDeclarationName,
typeToTypeNodeHelperWithPossibleReusableTypeNode,
typeParameterToDeclarationWithConstraint and signatureToSignatureDeclarationHelper
from the same pingdotgg/ts-rust commit (nodebuilder_impl_p2.rs), derived from
Microsoft TypeScript nodebuilderimpl.go. The copyright holders and MIT / Apache
License, Version 2.0 terms above also apply to these adaptations.

Changes made here: source metadata is attached to the native signatures and
excluded from structural equality and hashing; unchanged annotations are
serialized from the native AST. Generic substitutions retain the declaration
provenance, while changed types are synthesized. An opt-in dual text writer
records UTF-16 synthetic-node underlining independently of hover formatting.

Object property and accessor serialization also adapts propertyToTypeNode and
indexInfoToIndexSignatureDeclarationHelper (nodebuilder_impl_p3.rs and
nodebuilder_impl_p2.rs). Native object metadata retains the original member
annotations across spreads and substitutions, independently of hover output
and structural identity. Index signatures are synthesized, including readonly.

Setter-only object spread reads adapt getSpreadSymbol from checker_p15.rs in
that same ts-rust revision. The native object representation retains setter
kind through substitutions and inheritance, then copies undefined as the
spread value without changing the original annotated accessor type.

Class return-type inference adapts getReturnTypeOfSignature's resolution stack
from checker_p22.rs in that same ts-rust revision. Native class member shapes,
parameter scopes and AST bodies replace symbol links and signature targets;
lazy resolution preserves declaration-order independence and detects cycles.

Namespace declaration meaning adapts getModuleInstanceState and export-alias
resolution from ast/utilities_p3.rs in that same ts-rust revision. Native
statement slices replace parent-node links and retain cycle-safe resolution
while projecting namespace name types for the baseline writer.

Namespace value type-node serialization adapts symbolToTypeNode's value-space
type queries and symbol-chain lookup from nodebuilder_impl_p1.rs at the same
ts-rust revision. Native qualified namespace identities, lexical scopes and
ordered import aliases replace donor symbol links. Signature parameter scopes
participate in name qualification; the existing native inference engine now
resolves namespace member returns and namespace function exports directly.

Template placeholder relation matching

src/template_relations.rs adapts inferFromLiteralPartsToTemplateLiteral and
isValidTypeForTemplateLiteralPlaceholder from checker/relater_p3.rs in the
same pinned pingdotgg/ts-rust revision. Native text segments and Type values
replace arena IDs and donor string storage. Fixed delimiters determine each
captured placeholder, which is checked using the native type relation.
The copyright and license terms above also apply to this adaptation.

Declaration-based standard-library member instantiation

src/stdlib_members.rs adapts resolveTypeReferenceMembers and
resolveObjectTypeMembers from checker_p21.rs in the same pinned ts-rust
revision. Native library AST declarations, option-aware caches and type
substitution replace donor symbol tables and arena mappers. Method type
parameters retain their own scope; original annotations are reused only
when their type-parameter identity survives instantiation.

Predicate type-node serialization follows typePredicateToTypePredicateNodeHelper
and serializeInferredReturnTypeForSignature in nodebuilder_impl_p2.rs.
src/overload_failure.rs adapts getCandidateForOverloadFailure and
getLongestCandidateIndex from checker_p11.rs, preserving the selected failure
result while reporting the original overload diagnostic. The copyright and
license terms above also apply to these adaptations.

Primitive member lookup adapts getApparentType's primitive-to-wrapper mapping
from checker_p24.rs in the same pinned ts-rust revision. Native primitive and
literal receivers share the declaration-based member resolver and retain their
receiver identity when substituting polymorphic this types.

Library overload serialization retains declaration order as in
getSignaturesOfSymbol in checker_p22.rs. Context-sensitive function arguments
retain a callable provisional shape during native overload selection.

Contextual rest parameter typing adapts getRestTypeAtPosition from
checker/relater_p2.rs in the same pinned ts-rust revision. Native arrays,
tuples and rest elements preserve the remaining argument sequence.

Declaration-derived library index signatures and properties adapt
resolveObjectTypeMembers from checker_p21.rs and property-before-index lookup
from getPropertyTypeForIndexType in checker_p30.rs at the same pinned ts-rust
revision. Native type substitutions and inherited key domains replace donor
index-info tables without materializing incomplete structural library shapes.

Iterable reference displays elide matching trailing defaults following the
backwards-compatible argument elision in nodebuilder_impl_p3.rs at that same
revision. Native member resolution still instantiates the declaration defaults.

Lexical generic reference resolution adapts resolveEntityName from
checker_p17.rs and getTypeFromTypeReference from checker_p25.rs in that pinned
revision. Native declaration scopes distinguish parameters from same-named
program and library types; cached library declarations use an isolated
resolution environment.

Nested function-expression parameter identity and source-aware generic naming
adapt typeParameterToName (checker/nodebuilder_impl_p2.rs) and the scoped
name tables (checker/nodebuilder_scopes.rs) from the same pinned source.
Native declaration/file identities replace donor TypeId/symbol keys; the
native checker remains responsible for binding, inference and substitution.

Readonly property combination follows createUnionOrIntersectionProperty in
checker_p24.rs: unions retain any readonly declaration, while intersections
allow writes when a constituent declares the same property as mutable.

Class heritage type queries adapt getTypeOfNode (checker_p35.rs),
resolveBaseTypesOfClass and getInstantiatedConstructorsForTypeArguments
(checker_p21.rs), and isValidBaseType (checker_p22.rs) from the same revision.
Native construct signatures and declaration libraries supply base instances;
the type-query span keeps the instance while child names keep constructor
values. Class-expression display provenance follows createAnonymousTypeNodeEx
in nodebuilder_impl_p3.rs without replacing native nominal identities.
